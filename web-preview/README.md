# MalekPlay Web Preview

معاينة ويب تفاعلية لتصميم MalekPlay، مبنية داخل نفس المستودع وعلى الفرع `feature/zapya-engineering-analysis`.

## التشغيل محلياً
افتح `web-preview/index.html` مباشرة في متصفح حديث، أو شغّل خادماً محلياً من جذر المشروع:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080/web-preview/`.

## ما الذي تعرضه؟
- واجهات الرئيسية والأفلام والمسلسلات والموسيقى والمكتبة.
- UltraShare مع تبديل QR/رمز اقتران والتحقق من إدخال 9 أرقام (محاكاة).
- الشبكة والمفضلة وقوائم التشغيل والإعدادات ومشغل توضيحي.
- تصميم RTL متجاوب مع الهاتف والكمبيوتر، وألوان MalekPlay الذهبية/البنفسجية.

## حدود المعاينة
هذه واجهة ويب مستقلة تعيد تقديم التصميم والتفاعلات المرئية؛ ليست تشغيلًا لكود Jetpack Compose ولا بديلاً عن تطبيق Android. لا تصل إلى ملفات الجهاز ولا تنفذ تشغيل Media3 أو SMB/WebDAV/SFTP أو QR camera أو نقل الملفات الحقيقي. الأرقام والوسائط المعروضة بيانات توضيحية وليست مكتبة المستخدم. يجب اختبار تلك الوظائف داخل APK وعلى أجهزة فعلية.

## النشر
يحتوي المستودع على Workflow لنشر هذا المجلد إلى GitHub Pages عند الدفع إلى هذا الفرع. يجب أن تكون Pages مهيأة لاستخدام GitHub Actions في إعدادات المستودع.
