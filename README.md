# MalekPlay

مشغل وسائط Android بواجهة عربية RTL، مبني باستخدام Kotlin وJetpack Compose وAndroidX Media3.

## المنصة المستهدفة
- الحد الأدنى المعلن في إعدادات Gradle هو Android 6.0 (API 23 / minSdk 23).
- إصدار البناء المستهدف Android 15 (API 35 / targetSdk 35).
- المشروع مهيأ للاختبار على Samsung Galaxy Note 9، مع ضرورة التحقق من السلوك على أجهزة وإصدارات Android أخرى.
- بناء APK تجريبي وحزم Release عبر GitHub Actions.

> ملاحظة توافق: بعض واجهات Android الحديثة، مثل صلاحيات الوسائط الانتقائية، تعمل فقط على إصدارات أحدث. يظل الحد الأدنى API 23، لكن يجب اختبار مسارات الصلاحيات والتخزين على كل نطاق إصدارات مدعوم.

## المميزات المطبقة في المشروع
- مكتبة محلية للفيديوهات والصوتيات عبر MediaStore وRoom.
- البحث والترتيب والمفضلة وسجل التشغيل وقوائم التشغيل.
- تشغيل عبر Media3 مع خدمة مستقلة للصوت في الخلفية.
- استئناف التشغيل وسرعة افتراضية ومؤقت نوم.
- إيماءات السطوع والصوت والتقديم والرجوع وقفل عناصر التحكم.
- اختيار المسار الصوتي والترجمة الخارجية SRT.
- تغيير حجم الترجمة والمظهر الفاتح/الداكن/حسب النظام.
- معادل صوتي بخمسة نطاقات يعتمد على جلسة الصوت الفعلية؛ قد لا يتوفر مع كل مخرج صوتي.
- ترجمة ملفات SRT من الإنجليزية إلى العربية محلياً بعد تنزيل نموذج ML Kit؛ التنزيل الأول يحتاج اتصالاً بالإنترنت.
- حقن الاعتماديات Hilt لطبقات البيانات وViewModels والخدمات.
- طبقة اتصال WebDAV عبر HTTPS فقط، وSFTP مع التحقق من known_hosts، وSMB2/3.
- تشفير بيانات اعتماد مصادر الشبكة بمفتاح AES-GCM داخل Android Keystore.
- وضع أطفال محمي برمز PIN مع تأخير مؤقت بعد محاولات خاطئة، وإخفاء بعض أدوات المكتبة والإعدادات عند تفعيله.
- تصدير واستعادة إعدادات التطبيق والمفضلة وقوائم التشغيل بصيغة JSON مع التحقق من الحجم والإصدار.

## حدود معروفة قبل اعتبار النسخة مكتملة
- واجهات إدارة مصادر WebDAV/SMB/SFTP وربط المصادقة بتشغيل الوسائط داخل المشغل ما زالت تحتاج استكمالاً؛ طبقات الاتصال الحالية ليست بعد تجربة تصفح وتشغيل متكاملة من الواجهة.
- النسخ الاحتياطي الحالي لا ينسخ ملفات الوسائط ولا قاعدة Room الحية أو ملفات الفيديو؛ يقتصر على الإعدادات والمفضلة وقوائم التشغيل.
- وضع الأطفال حالياً يخفي أدوات معينة ويحمي إيقاف الوضع برمز PIN؛ لا يتضمن بعد تصنيف محتوى أو قائمة سماح/حظر لكل ملف.
- تحسينات عرض الترجمة وحجمها وترجمتها الآلية موجودة، أما دمج libass الأصلي وتنسيقات ASS/SSA المتقدمة فما زال بحاجة إلى بناء واختبار منفصل على ABI الخاص بأجهزة Android.
- نجاح GitHub Actions يثبت نجاح التجميع والاختبارات الآلية المحددة فقط، ولا يثبت الاختبار التشغيلي على كل جهاز فعلي.

## البناء والاختبار
- الاختبارات السريعة في CI: اختبارات الوحدات وAndroid Lint وتجميع Debug APK وRelease APK وAndroid App Bundle.
- لا يشغّل خط CI محاكي Android أو اختبارات UI على المحاكي؛ تم استبعادها لتجنب وقت الإقلاع الطويل. يمكن تنفيذ تحقق UI يدوياً على هاتف فعلي عند الحاجة.
- افتح تبويب Actions في المستودع.
- اختر أحدث تشغيل ناجح من workflow المسمى Build MalekPlay Android APK.
- نزّل artifact المسمى MalekPlay-debug لتثبيت نسخ Debug حسب ABI، أو MalekPlay-universal-install للتثبيت المباشر على أجهزة Android المدعومة.
