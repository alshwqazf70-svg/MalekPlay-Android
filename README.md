# MalekPlay

مشغل وسائط Android بواجهة عربية RTL، مبني باستخدام Kotlin وJetpack Compose وAndroidX Media3.

## المنصة المستهدفة
- Android 10 فأحدث.
- تصميم موجه للاختبار على Samsung Galaxy Note 9.
- بناء APK تجريبي عبر GitHub Actions.

## المنجز
- واجهة عربية فاتحة.
- مكتبة محلية للفيديوهات والصوتيات عبر MediaStore.
- أذونات وسائط متوافقة مع Android 10 وAndroid 13+.
- تصنيف المكتبة إلى الكل والفيديوهات والصوتيات.
- البحث بالاسم، والترتيب بالأحدث، وإظهار المدة والحجم.
- صور مصغرة للفيديوهات.
- تشغيل الملفات عبر AndroidX Media3 / ExoPlayer.
- فتح ملف يدوي من منتقي ملفات Android.

## خارطة الطريق
1. تحسين المكتبة والمجلدات وسجل المشاهدة.
2. تطوير المشغل والإيماءات والترجمة والمسارات الصوتية.
3. قوائم التشغيل والصوت بالخلفية والمعادل الصوتي.
4. اختبارات الأداء والتوافق والاستقرار.

لا تُعد الميزات المخطط لها منجزة حتى تُنفذ وتُختبر.
