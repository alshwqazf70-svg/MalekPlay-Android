# MalekPlay

مشغل وسائط محلي متقدم لنظام Android، بواجهة عربية RTL، مبني باستخدام Kotlin وJetpack Compose وAndroidX Media3.

## الهدف
- تشغيل ملفات الفيديو والصوت المحلية.
- دعم Android 10 وما بعده، مع استهداف Samsung Galaxy Note 9.
- واجهة عربية فاتحة واتجاه RTL.
- إعطاء الأولوية للاستقرار والأداء قبل إضافة الميزات المتقدمة.

## حالة المشروع
تم تهيئة المستودع. سيُضاف هيكل التطبيق وإعدادات البناء وعمليات التحقق تدريجياً.
